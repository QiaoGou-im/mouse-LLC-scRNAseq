# Single-cell analyses for “Targeting a Treg-driven multicellular relay limits pathological immunosuppression”

## Overview

This repository contains analysis code accompanying the manuscript “Targeting a Treg-driven multicellular relay limits pathological immunosuppression”.

The analyses investigate the role of Treg-derived, GARP-mediated TGF-β1 activity in lung cancer progression using two complementary single-cell datasets:

1. **Single-cell RNA sequencing (scRNA-seq):**
   Analysis of lung immune cells from control and Lrrc32^fl/fl Foxp3-Cre⁺
   mice inoculated with Lewis lung carcinoma (LLC) cells.

2. **Single-cell multiome sequencing (scRNA-seq and scATAC-seq):**
   Joint analysis of gene expression and chromatin accessibility in lung
   immune cells from LLC-inoculated wild-type (WT) mice receiving either
   control treatment or MERIT treatment.

## Data availability

The sequencing data generated in this study are available in the DNA Data Bank of Japan (DDBJ) under accession number PRJDB17170.

## Analysis code

Analysis scripts are being organized and will be added to this repository.
